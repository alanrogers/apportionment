It has been known since the early 1970s that differences between
continental human populations account for only a small fraction of
total genetic variation \citep{Lewontin:EB-6-381, Nei:S-177-434}.  On
this basis, Richard Lewontin concluded that racial classification was
``of virtually no genetic or taxonomic significance''
\citep[p.~397]{Lewontin:EB-6-381}. In the half-century since these
papers appeared, this interpretation has been criticized
\citep{Spielman:AJH-28-317, Mitton:AN-111-203, Edwards:BE-25-798} and
defended \citep{Shen:PRS-377-20200417}. It is also sometimes broadened
into a stronger claim: that when the between-group component of
genetic variance is small, there can be no important genetic
difference between the groups. This must be true in the limiting case
when there are no genetic group differences at all. But what if these
differences are merely small, but not zero? How much does this
constrain group differences in, say, a quantitative character?

One answer to this question was suggested by Lewontin himself, who
pointed out that the loci contributing to a particular character may
differ more between populations than predicted from the genome-wide
average \citep{Lewontin+Krakauer:73}, an idea that is often used in
recent literature \citep[e.g.\ ][]{Norton:MBE-24-710}. This note will
provide a different answer, which focuses on the loci contributing to
the character. If \emph{these} loci vary only slightly among groups,
how much does this constrain group differences in the character they
control?

I will show that this constraint is minimal if the number of loci is
large. This reflects the fact---demonstrated below---that the
difference between character means scales with $K$, the number of
loci, whereas the within-group standard deviation of character value
scales with $\sqrt{K}$. If $K$ is large, the difference between groups
may amount to many standard deviations. The same idea underlies a
well-established model of limits to selection on a quantitative
character \citep[pp.~218--219]{Falconer:IQG-96}.

To model this idea, let us consider a set of $K$ genetic loci, which
vary within two populations of equal size. At each locus there are two
alleles, called ``plus'' and ``minus'' for reasons explained
below. The frequency of each plus allele is $p_1 = 1/2 + \delta$ in
population~1, $p_2 = 1/2 - \delta$ in population~2, and $\bar p = 1/2$
in the population as a whole. Let us use this model to calculate
Wright's $F_{ST}$, which measures the proportional reduction in
heterozygosity caused by differences among populations. It is by
definition $F_{ST} = B\big/\{\bar p(1-\bar p)\}$, where $B$ is the
between-group component of variance in allele frequencies
\citep{Wright:AE-15-323}. For our model, $B = (p_1 - 1/2)^2/2 + (p_2 -
1/2)^2/2 = \delta^2$. This implies that
\[
  F_{ST} = 4\delta^2
\]
Our question now becomes, if $F_{ST}$ is small for a set of loci, how
much does this constraint the difference between groups in a
quantitative character controlled by these loci?

I assume that at each locus the plus allele adds one unit to character
value, and the minus allele subtracts one unit. The environment is the
same in both groups and therefore makes no contribution to the
difference between groups.  With this setup, each locus contributes
$4\delta$ to the mean character value in population~1 and $-4\delta$
to that in population~2. Each locus thus contributes $8\delta$ to the
difference between populations. Summing across loci,
\[
D = 8K\delta
\]
is the difference in mean character value between the populations.

We turn now to variance within groups. Heritability within each
population is by definition $h^2 = V_G/(V_G + V_E)$, where $V_G$ and
$V_E$ are the additive genetic and environmental components of
variance. The total variance within groups can thus be written as $V_G
+ V_E = V_G h^{-2}$.  The additive genetic variance contributed by a
single locus within population~$i$ is $2p_i(1-p_i)\alpha^2$, where
$\alpha=2$ is the average effect of a gene substitution
\citep{Fisher:AE-11-53}. For either population, this equals $2(1 -
4\delta^2)$. Summing across loci,
\[
V_G = 2K(1 - 4\delta^2)
\]
The variance here is a sum of per-locus contributions, because I have
assumed linkage equilibrium within each population between all pairs
of loci.

The mean difference between the character values of the two
populations, expressed in units of the within-population standard
deviation, is
\begin{eqnarray*}
  \frac{D}{\sqrt{V_G + V_E}} &=&
  \frac{8K\delta}{\sqrt{h^{-2}2K(1 - 4\delta^2)}}\\
  &\approx& 5.7 h\sqrt{K}\delta
\end{eqnarray*}
where the approximation is good if $\delta^2$ is small.  To make this
concrete, let us assume that $\delta=0.1$ so that $F_{ST} = 0.04$---a
value somewhat smaller than that of the continental human
populations. If heritability is $h^2=0.5$, and the number of loci is
$K=100$, then the two populations differ by 4 standard
deviations. Fig.~\ref{fig.4sigma} shows what this would look like. The
two distributions are well separated, with only minor overlap. If
instead there were 1000 loci, the difference would exceed 12 standard
deviations.

\begin{figure}
  {\centering\includegraphics[width=0.5\textwidth]{4sigma.pdf}\\}
  \caption{Two normal distributions with means 4 standard deviations
    apart.}
  \label{fig.4sigma}
\end{figure}

These results show that small differences in allele frequencies can
cause large differences in a quantitative character.  A small value of
$F_{ST}$ does not preclude substantial genetic differences between
populations.
